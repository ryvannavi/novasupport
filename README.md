# NovaSupport — AI-Powered Helpdesk & Support System

A full-stack customer support system built for a tech company, featuring AI-generated replies with human admin approval workflow.

## Tech Stack
- **Backend:** PHP / Laravel 11
- **Database:** SQLite
- **Frontend:** Blade + Tailwind CSS + AlpineJS
- **AI:** Groq API (LLaMA 3.3 70B)
- **Charts:** ApexCharts
- **Deployment:** Railway

## Features
- Customer ticket submission and tracking
- AI auto-generated replies via Groq API
- Admin approval workflow before customer sees reply
- Real-time notifications
- Analytics dashboard with charts
- FAQ knowledge base with live search
- Customer star ratings
